# Data access

This repository does not redistribute participant-level NHANES or KNHANES data.

- NHANES source data and documentation: obtain from the U.S. National Center for Health Statistics.
- KNHANES source data and documentation: obtain from the Korea Disease Control and Prevention Agency.

The repository contains source code, model metadata, aggregate summaries, and verification outputs only. Users are responsible for complying with the official source-data terms and for recreating analysis-ready files locally.
