# Manuscript sensitivity analysis: age-only versus age+height reference

This directory documents the controlled sensitivity analysis added in manuscript
revision v2.1.0. Its purpose is to isolate the contribution of explicit stature
conditioning; it does **not** change the public age+height scorer or the frozen
primary model objects.

## Analysis logic

The age-only comparator removes height from the GAMLSS location predictor while
holding constant the following features of the primary age+height analysis:

- sex-specific family (women BCCG; men BCT);
- age smooth (df=3; with the same female numerical basis stabilization);
- constant sigma and intercept-only shape parameters;
- corrected pooled MEC development weights;
- five completed NHANES 1999-2006 DXA datasets;
- deterministic PSU-grouped five-fold allocation;
- frozen application to NHANES 2011-2018 without refitting.

The comparator is **not** intended to reproduce the model of Wang et al. or any
other published age-only reference. It is an otherwise-identical controlled
comparison in which stature conditioning is the only changed model component.

## Development data

The script uses the `train_data` frames preserved inside the frozen v2.x primary
model bundles:

- `models/corrected_H_18_69_Female_bundles.rds`
- `models/corrected_H_18_69_Male_bundles.rds`

These are the final corrected-weight development data frames used by the frozen
1999-2006 fits.

## Validation data

Participant-level NHANES 2011-2018 validation data are not redistributed in this
repository. Run the script with the analysis-ready validation file generated by
the archived manuscript pipeline:

```bash
Rscript analysis/age_only_vs_age_height_comparator.R /path/to/validation_corrected_H_18_59.rds
```

or set:

```bash
export ALM_VALIDATION_FILE=/path/to/validation_corrected_H_18_59.rds
Rscript analysis/age_only_vs_age_height_comparator.R
```

The file may be `.rds`, `.csv`, or `.csv.gz`. Required variables are:

- `sex` (`Female`/`Male`)
- `age`
- `height_m` or `height_cm`
- `alm_kg`
- `wtmec_pool`
- `strata_pool`
- `psu_pool`
- `race`
- `cycle`
- `imputation` (1-5); if absent, the script expands each row to the five frozen
  development-model imputations

If age+height score columns are absent, the script recalculates them from the
frozen v2.x model bundles.

## Archived expected results

`expected/age_only_vs_age_height_expected.csv` contains the manuscript-level
results used to audit a successful rerun. Key values include:

- age-only continuous z slope per 10 cm: +0.644 in women and +0.708 in men;
- age+height continuous z slope per 10 cm: +0.018 in women and -0.052 in men;
- P5 reclassification: 2.80% in women and 4.42% in men;
- P10 reclassification: 6.33% in women and 7.73% in men.

Minor last-decimal differences can arise from software/platform details; the
recorded environment in `environment/` should be used for formal reproduction.
